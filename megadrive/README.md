# 第3部　メガドライブ編 ── MeijinOS68k（MC68000）

書籍『OS の基本実装概要 ― 四つの機械で、同じ骨格を四度つくる』第3部（第18〜26章）・付録G のソースコードです。
68000 のスーパーバイザ／ユーザの二段特権の上で、心臓部 13 命令の OS を組み上げます。

```asm
Yield:
    ori.w   #$0700,sr           ; ⓪ 割り込みを止める（切り替え中は触らせない）
    movem.l d0-d7/a0-a6,-(sp)   ; ① 世界を封印
    lea     TaskTable,a0        ; ② 台帳へ、いまのSPを記録
    move.w  CurTask,d1
    move.w  d1,d0
    lsl.w   #3,d0
    move.l  sp,(a0,d0.w)
    bsr     SelectNext          ; ③ 次を選ぶ
    move.w  d0,CurTask          ; ④ 台帳から引く
    lsl.w   #3,d0
    move.l  (a0,d0.w),sp        ; ⑤ SPを差し替える ＝ 世界の切り替え
    movem.l (sp)+,d0-d7/a0-a6   ; ⑥ 世界を復元
    rte                         ; ⑦ 向こうの世界へ帰る
```

⓪ は、68000 の trap が割り込みマスクを上げないための備えです（第20章5節）。

## ビルド

必要なのは [vasm](http://sun.hasenbraten.de/vasm/)（m68k / Motorola syntax）だけです。

```sh
make            # 全部ビルド
make coop.bin   # 一つだけ
vasmm68k_mot -Fbin -o coop.bin coop.asm     # 手で叩く場合
```

Windows で `make` が無い場合は `build.bat`（`build.bat coop` / `build.bat clean` / `build.bat verify`）。

できた `.bin` を [BlastEm](https://www.retrodev.com/blastem/) などに読み込ませてください。実機でも動きます。

## 動かすと、何が見えるか

**`coop.asm`** ── 上下の行に同じ値が並んで増えていきます（`2A = 2A`）。

**`preempt.asm`** ── どちらのタスクも `trap #0` を呼びません。それでも両方が動きます（`48A1` 対 `3FBA`、第20章7節）。

**`meijin10.asm`** ── 三人の住人が同居します。時計、A ボタンのカウンタ、譲らないゾンビ。Start＋A でゾンビを殺せます（第25章6節）。

**`crash.asm`** ── タスク 0 が配列の大きさを間違え、隣のタスク 1 を踏み潰します。CPU は何も言いません（第26章3節）。

**`trace.asm`** ── タスク 1 の SR の T ビットを立てると、1 命令ごとに例外が起きます。デバッガの「ステップ実行」の正体です（第25章4節）。
