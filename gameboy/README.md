# 第2部　ゲームボーイ編 ── MeijinOS（LR35902）

書籍『OS の基本実装概要 ― ゲームボーイ・メガドライブ・GBA・RISC-V ― 四つの機械で、同じ骨格を四度つくる』第2部（第8〜17章）・付録G のソースコードです。
8 ビット・8KB・保護なしの機械で、心臓部 32 命令の OS を v0.1 → v0.2 → v1.0 と育てます。

## ビルド（RGBDS 0.9 系で検証済み。1.0 系でも同じ三行）

```sh
rgbasm  -o coop.o  coop.asm
rgblink -o coop.gb -n coop.sym coop.o   # -n でシンボル表（BGB が自動で読む）
rgbfix  -v -p 0xFF coop.gb
```

`make` があれば `make` 一語で全部できます（`Makefile`）。

## 実行

`.gb` を BGB（Windows）、SameBoy / Emulicious（macOS / Linux / Windows）などにドラッグ＆ドロップしてください。
`coop.gb` / `preempt.gb` は画面左上に二つの 16 進カウンタが出ます。協調版は `171 = 171` のように揃い、
プリエンプティブ版は揃いません（第13章5節）。
